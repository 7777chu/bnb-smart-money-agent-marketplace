### Project Description

BNB Smart Money Agent Marketplace is a financial-agent discovery and hiring marketplace for BNB Chain. It helps users find and compare AI agents across four categories: grid trading, LP rebalancing, yield optimization, and health-factor monitoring.

Each agent profile shows what the agent does, supported protocols, on-chain identity, permission scope, cost, risk level, execution history, and performance indicators. Users can hire an agent with scoped session permissions such as allowlist, spend cap, and expiry, then revoke access anytime.

The MVP focuses on BNB Agent Studio-compatible agents and Smart Money use cases around PancakeSwap, yield routing, and lending risk monitoring. The submission will include BSC testnet transaction proof, Altana-style session permission proof, and an Agent Advantage Report comparing agent workflows against manual workflows by time, cost, and output quality.

The goal is to make BNB Chain the default home for discoverable, comparable, and safe-to-hire financial AI agents.
