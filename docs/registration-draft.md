## Project Name

BNB Smart Money Agent Marketplace

## Short Description

A marketplace for BNB Chain AI agents that helps users discover, compare, and hire Smart Money agents for grid trading, LP rebalancing, yield optimization, and lending health-factor monitoring, with transparent on-chain identity, session permissions, risk limits, and performance data.

## Long Description

BNB Chain has a growing AI-agent ecosystem, but the user journey is still fragmented: users cannot easily find relevant agents, understand what they do, compare their historical performance, inspect permissions, or hire them safely. BNB Smart Money Agent Marketplace solves this by creating a canonical front door for financial agents on BSC.

The product surfaces four core categories: grid trading, LP rebalancing, yield optimization, and health-factor monitoring. Each agent profile includes capability, supported protocols, on-chain identity, wallet/session permission scope, cost, risk level, execution history, and performance indicators. Users can hire an agent, set spend caps and expiry, review allowed calls, and revoke permissions from the product.

The first MVP focuses on PancakeSwap, Venus/Lista-style yield and lending scenarios, and BNB Agent Studio-compatible agents. The project will include live testnet transactions, Altana session-key permission proof, and an Agent Advantage Report comparing agent execution against manual workflows.

## Why It Matters

Smart Money should not depend on knowing insiders or manually monitoring protocols 24/7. Users need agents available on demand, but they also need trust, comparability, and safety. This marketplace makes agent-based finance discoverable and usable for normal DeFi users.
