# Demo Video Script — 2-3 Minutes

## Goal

Show judges that **BNB Smart Money Agent Marketplace** is not only a landing page. It is a complete user flow for discovering, comparing, hiring, monitoring, and revoking financial AI agents on BNB Chain.

Recommended recording URL: https://bnb-smart-money-agent-marketplace.vercel.app

## 0:00-0:15 — Hook / Problem

> Today, financial AI agents are hard to trust. Users can find bots, dashboards, and protocol tools, but they still cannot answer the key questions: Which agent is safe? What permissions will it get? What does it cost? Can I revoke it? Did it actually perform better than doing the DeFi work manually?

Visual: open homepage hero.

## 0:15-0:35 — Marketplace Homepage

> This is BNB Smart Money Agent Marketplace — a front door for BNB Chain financial agents. The MVP organizes agents into four Smart Money categories: grid trading, LP rebalancing, yield optimization, and health-factor monitoring.

Visual path:

1. Show homepage headline.
2. Scroll to Featured Smart Money Agents.
3. Point out category, protocol, risk, performance, session scope, spend cap, and expiry.

## 0:35-0:55 — Compare Agents

> Before hiring an agent, the user can compare risk level, supported protocols, cost model, permission scope, and bounty fit in one place. This turns agents from black boxes into comparable financial products.

Visual path:

1. Click **Compare agents**.
2. Show the four agent cards.
3. Mention: Health Factor Guardian is lower risk, Grid Alpha is higher risk but more active.

## 0:55-1:20 — Agent Profile

> Opening an agent profile gives the user the details needed before giving any permission: best use case, safety controls, session policy, performance targets, and pending chain proof.

Visual path:

1. Open `/agents/grid-alpha`.
2. Highlight best-for, safeguards, metrics, protocols, and session policy.

## 1:20-1:45 — Hire / Permission Flow

> The hire flow is designed around safety. The user does not give unlimited wallet control. The session has an allowlist, spend cap, expiry, and revoke path. This is the core trust layer for self-custodial financial agents.

Visual path:

1. Open `/hire/grid-alpha`.
2. Highlight allowlist, spend cap, expiry, revoke.
3. Click or show **Simulate hire** and **Revoke session** if recording interaction works smoothly.

## 1:45-2:05 — Dashboard / Ongoing Control

> After hiring, the user needs ongoing control. The dashboard shows active sessions, cap usage, current health, next action, last action, permission scope, expiry, and revoke entry.

Visual path:

1. Open `/dashboard`.
2. Show Grid Alpha, LP Range Keeper, Health Factor Guardian.
3. Show recent action log.

## 2:05-2:30 — Agent Advantage Report

> For the TermiX track, the product includes an Agent Advantage Report. It compares agent execution against manual DeFi work across time saved, monitoring quality, risk enforcement, and cost transparency.

Visual path:

1. Open `/report`.
2. Show Marketplace scorecard 4/4.
3. Scroll through the comparison cards.

## 2:30-2:50 — Proof Center / Bounty Fit

> The Proof Center collects the live demo, GitHub repo, bounty mapping, and next on-chain proof sprint. It maps directly to the main track, TermiX, PancakeSwap, and Altana/session-key style permission controls.

Visual path:

1. Open `/proof`.
2. Show live links.
3. Show Bounty / track coverage.
4. Show next proof sprint.

## 2:50-3:00 — Close

> BNB Chain does not just need more agents. It needs a trusted marketplace where users can discover, compare, hire, monitor, and revoke Smart Money agents safely. That is what this MVP demonstrates.

## Recording Checklist

- Use browser zoom 100% or 90%.
- Keep the URL bar visible at least once for credibility.
- Do not show private tabs, wallets, keys, email, Telegram, or GitHub/Vercel admin pages.
- Record only the public demo URL.
- If the recording feels long, skip the detailed scroll on `/report` and keep the full flow under 3 minutes.
