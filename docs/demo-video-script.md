# Demo Video Script — 2-3 Minutes

## 0:00-0:20 — Hook

Today, finding a useful financial agent on-chain is still messy. Users have to jump between docs, explorers, dashboards, and communities, and still cannot tell which agent is safe or worth paying for.

BNB Smart Money Agent Marketplace fixes that.

## 0:20-0:50 — Homepage

Here is the marketplace homepage. Agents are organized by the four financial categories BNB Chain cares about: grid trading, LP rebalancing, yield optimization, and health-factor monitoring.

Each card shows what the agent does, supported protocols, cost, risk, recent activity, and performance summary.

## 0:50-1:25 — Agent Detail

Opening an agent page, users can inspect its on-chain identity, supported protocols, execution history, risk level, and session policy. The goal is simple: users should understand the agent before hiring it.

## 1:25-1:55 — Hire Flow / Safety

When hiring, the user sets a spend cap, expiry time, and allowed actions. The session key is scoped. The user can review exactly what the agent may do and revoke permissions anytime.

This is important because financial agents should not be black boxes controlling user funds.

## 1:55-2:20 — Partner Fit

The product supports BNB Agent Studio agents, Altana-style self-custodial sessions, 8004scan identity/reputation data, and PancakeSwap trader/LP use cases.

## 2:20-2:50 — Agent Advantage

We also include an Agent Advantage Report. For real tasks, we compare using an agent versus doing it manually, measuring time, cost, and output quality.

## 2:50-3:00 — Close

This marketplace makes Smart Money agents discoverable, comparable, and safe to hire. The goal is to become the canonical front door for financial AI agents on BNB Chain.
